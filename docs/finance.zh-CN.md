# 统一记账与周期付款

Docker/Go 版本提供统一账本，不必创建资金账户。主导航为「总览」「账单」「订阅」「分析」「设置」。Cloudflare 版本当前继续提供订阅管理，尚未启用账本和付款联动。

## 记一笔与查看账单

桌面顶部与手机底部都有「记一笔」，在任何主要页面均可登记收入或支出。金额输入框默认获得焦点，分类优先显示最近使用项；币种、日期、商家与标签可在「更多信息」中补充。可选择「保存并再记一笔」连续录入。未保存的内容在当前浏览器标签页保留草稿，关闭时可选择保留或放弃；草稿按用户与具体账单/付款分开存储。收到的转账使用收入分类。

消费退款从「账单」中原支出的「退款」按钮登记，支持部分退款，累计原币退款不能超过原消费金额。退款沿用原消费的分类、商家及周期来源，按实际到账日期冲减净支出，不计入收入；跨月退款不改写原消费日期。总览与分析展示净支出，并同时列出原始支出和退款金额。历史使用「退款」收入分类的记录也计入退款；没有原消费关联的历史退款单独展示，不猜测其消费分类。

「账单」集中展示日常消费和周期付款，可以按日期、分类、商家及日常/周期来源筛选。分类表达消费用途，例如房租、娱乐、工作；是否来自订阅或其他周期计划另行标记。账单支持更正、填写原因后作废，以及变更记录。更正经过版本校验，避免覆盖其他页面的修改。

订阅确认付款时，默认沿用订阅分类，显示为「订阅-生产力」「订阅-影音流媒体」等；未分类使用「订阅-其他」。自定义订阅分类也自动成为支出分类选项，无需在账本中重复添加。普通记账选择订阅分类不会自动关联订阅或推进续费日期。付款时可调整本次账单分类，关联已有账单时保留该账单的分类。

订阅分类变更会同步到后续待确认付款；旧版付款计划的默认分类也自动更新，已有账单不改写。总览和分析的消费分布将这些分类合并为「订阅」，展开可查看细分；点击「订阅」或细分项可筛选相应账单。房租等其他周期计划仍使用住房等普通消费分类。

外币记录保留原币金额，并保存实际人民币金额。登记时可使用当前汇率建议值，也可填写银行卡或支付平台实际扣款的人民币金额。历史总额采用保存的人民币金额，不随之后的汇率变动。旧外币记录缺少折算金额时，总览和分析显示提示；编辑补全后才进入人民币合计。

## 周期支出与待确认付款

「账单 → 周期计划」管理房租、家庭账单及其他周期支出。「订阅」管理服务订阅，现有周期订阅自动关联付款计划；一次性买断不创建周期计划。迁移保留原订阅信息与已知下次付款日期，不推断旧日期对应的历史付款。

付款日期到来后生成待确认事项，不会自动产生实际支出，也不会自动推进日期。确认支持三种操作：

- **记入支出**：确认原币金额、实际人民币金额、消费分类与实际付款日期后，创建一笔关联账单并推进下一次付款日期。
- **关联已有账单**：选择已记过的支出，将其关联到本次付款，避免重复记账。确认页根据币种、金额、商家和计划日期或实际处理日期附近的账单推荐候选；出现相似账单时，新增付款需要明确确认不是重复记账。候选列表支持搜索已加载记录和继续加载。
- **跳过本次**：填写原因后推进日期，保留跳过记录，不产生支出。

重复确认同一次付款不会重复入账。作废关联账单会重新打开该次待确认付款；重新确认时会越过已处理的后续日期。月末周期保留原始日期锚点，例如 1 月 31 日 → 2 月末 → 3 月 31 日。计划可暂停、取消或设置截止日期；编辑订阅或对应付款计划时双方保持同步。

待确认付款不会自动将活跃周期订阅改为已过期，订阅卡片会标记「待确认」。用户显式暂停、取消或设为已过期的状态继续保留；一次性固定服务期仍按其到期日判断权益是否结束。

## 总览、订阅与分析

「总览」围绕实际消费展示本月净支出、收入、结余、已付周期净支出、日常/周期消费筛选、收支趋势、用途分布和付款安排。待付计划使用当前汇率估算，单独展示，确认前不会计入实际支出。支出变化按相同截止日期比较上月。

「订阅」默认展示搜索与服务列表，日历、概览与成本分布集中在「日历与统计」中。预估月成本是周期摊算结果，例如年付 1200 元折合每月 100 元；另行展示本月订阅实付净额，按关联付款和退款统计。订阅详情可查看累计人民币付款及最近账单。

「分析」统计所有已记账的收支，统一展示人民币合计、趋势、用途分布、周期支出占比和商家支出。日期范围最多 366 天，可从分类和商家跳转查看对应账单。原独立日历入口转入「订阅 → 续费日历」，原订阅统计放在「订阅 → 订阅分析」。

## 备份与兼容

「账单」下方展开账本设置与导出，可导出独立 JSON，恢复前查看预览。原 Renewlet ZIP 与 Docker 云备份包含 finance 段及周期计划、付款记录；普通订阅 CSV 仍是订阅清单。恢复仅写入空账本，经过完整校验后在事务内写入。重复提交同一快照不会重复记账，账单与计划的关联会映射到新 ID。

旧账户、期初余额、转账、退款及预算数据保留读取与恢复兼容，新记账流程不使用账户与预算。旧外币需要补充人民币金额。旧备份没有 finance 段时保留当前账本。升级前可备份 Docker data 目录，启动迁移支持重复执行。

接口位于 `/api/app/finance`，使用网页登录与 CSRF；原 Public API Token 继续只读订阅。
